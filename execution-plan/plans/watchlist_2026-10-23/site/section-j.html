The Create New Watchlist name field is prefilled with 'WatchList N' and the cursor goes to the end, so users must delete it first. Select the whole text when the field gets focus, so typing replaces it and leaving it keeps the default.

Teams FEProductRisk LowEffort S · ≤ 1 dayVisible to usersDepends on A1

Today

initState computes 'WatchList ${n}' and creates TextEditingController(text: watchlistName). Nothing selects the text, so typing appends to it.

What to change

  1. Add FocusNode _nameFocus; listener: if hasFocus and flag on, _controller.selection = TextSelection(baseOffset: 0, extentOffset: _controller.text.length).
  2. Pass focusNode to the TextField; dispose it.

J5

Keep the header height fixed while the wealth tile changes

The developer saw the list shift while the header's wealth tile rotates. The tile sits in a box of fixed height (5.5 % of screen height) with an AnimatedSize inside, so the shift probably comes from the tile switching between nothing (SizedBox.shrink) and content when its stream re-emits, which changes the header row's height. Reserve the tile's height in all states.

Teams FE · sharedRisk LowEffort S · ≤ 1 dayVisible to usersverify on device

Today

WealthOverviewTile returns const SizedBox.shrink() when the snapshot has no data or the tile list is empty, and _WealthOverviewTileContent otherwise, which is a SizedBox of MediaQuery height × 0.055. The landing header is in a SliverToBoxAdapter above the list, so any header height change moves the list. Which of these states occurs during rotation was not observed (verify with the Flutter inspector's layout explorer while it rotates).

What to change

  1. Confirm with the inspector which widget changes height.
  2. If it is the shrink/content switch, return a same-size empty box.
  3. If it is the AnimatedSize, clamp its child height to the outer box.
