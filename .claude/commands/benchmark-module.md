---
description: Define a new benchmark module or edit an existing one (screens per app, list, gestures, items)
argument-hint: <module-name>
---

Use the `benchmark-runner` agent in mode **module** for `$ARGUMENTS`.

If `$ARGUMENTS` is empty, ask for the module name (lowercase, underscores, e.g. `us_stocks`).
Never overwrite an existing module without showing the change and the version hash before and
after.
